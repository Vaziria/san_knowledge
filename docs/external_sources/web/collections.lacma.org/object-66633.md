# Incense Burner Cover

- **Artist/Maker:** Unknown
- **Date:** 14th-15th century
- **Place:** Indonesia, Eastern Java, Trowulan region
- **Medium:** Earthenware
- **Dimensions:** 3 1/4 x 3 1/2 x 3 3/4 in. (8.26 x 8.89 x 9.53 cm)
- **Credit Line:** Gift of Marilyn Walter Grounds
- **Accession Number:** AC1993.239.4

This hand-built earthenware cover comes from the Trowulan area, the former capital of the Majapahit Empire. It takes the form of a now-headless woman, with perforations in her chest and base that let smoke escape. Objects like this were also sometimes used as fertility decoration.
