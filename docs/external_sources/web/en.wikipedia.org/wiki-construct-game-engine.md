**Construct** is an [HTML5](https://en.wikipedia.org/wiki/HTML5 "HTML5")-based [2D](https://en.wikipedia.org/wiki/2D_computer_graphics "2D computer graphics") [video game engine](https://en.wikipedia.org/wiki/Video_game_engine "Video game engine") developed by Scirra Ltd.[\[4\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-Create_games_with_Construct_2-4)[\[5\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-5) It is aimed primarily at non-programmers,[\[6\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-6) allowing quick creation of games through [visual programming](https://en.wikipedia.org/wiki/Visual_programming_language "Visual programming language"). First released as a [GPL-licensed](https://en.wikipedia.org/wiki/GNU_General_Public_License "GNU General Public License") [DirectX 9](https://en.wikipedia.org/wiki/DirectX "DirectX") game engine for [Microsoft Windows](https://en.wikipedia.org/wiki/Microsoft_Windows "Microsoft Windows") with [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29 "Python (programming language)") programming on October 27, 2007, it later became proprietary software with Construct 2, as well as switching its API technology from DirectX to [NW.js](https://en.wikipedia.org/wiki/NW.js "NW.js") and [HTML5](https://en.wikipedia.org/wiki/HTML5 "HTML5"), while removing Python and adding [JavaScript](https://en.wikipedia.org/wiki/JavaScript "JavaScript") support and its plugin SDK in 2012,[\[7\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:1-7) and eventually switched to a subscription-based web app model.[\[8\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:0-8)

## Features

### Event system and behaviors

The primary method of programming games and applications in Construct is through 'event sheets', which are similar to source files in programming languages. Each event sheet has a list of events, which contain conditional statements or triggers. Once these are met, actions or functions can be carried out.[\[9\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-9) Event logic such as [OR](https://en.wikipedia.org/wiki/Logical_disjunction "Logical disjunction") and [AND](https://en.wikipedia.org/wiki/AND_gate "AND gate"), as well as sub-events (representing [scope](https://en.wikipedia.org/wiki/Scope_%28programming%29 "Scope (programming)")) allow for sophisticated systems to be programmed without learning a comparatively more difficult programming language.[\[10\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-10) Groups can be used to enable and disable multiple events at once, and to organize events.[\[11\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-11)

### Object instance selection

Unlike many traditional development environments, Construct eschews selecting specific instances of objects when adding events, in favor of filtering through all instances of an object type on screen. When adding events, the editor allows the user to specify conditions or checks that must be fulfilled by each object instance on the screen before the event will be added or run by it. Events can be chained together using sub-events, allowing for more complicated behaviors to be created.[\[12\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-12)

### JavaScript

Construct 3 supports JavaScript as an optional scripting language which was announced in May 2019, citing the need to satisfy the advanced users' needs and popularity of existing workarounds.[\[8\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:0-8)

## Supported platforms

The latest version of Construct supports many platforms to export to, such as [web applications](https://en.wikipedia.org/wiki/Web_application "Web application") and playable advertisements, to dedicated programs and [mobile apps](https://en.wikipedia.org/wiki/Mobile_app "Mobile app").[\[13\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-13) Previous versions of Construct also supported other online platforms and storefronts, but have since been removed due to low use or service changes to the platform.

### Construct Classic

Construct Classic can only export to [.exe](https://en.wikipedia.org/wiki/.exe ".exe") files, due to its reliance on DirectX.

### Construct 2

#### HTML5 and storefronts

Construct 2's primary export platforms are HTML5 based. It claims support across [Google Chrome](https://en.wikipedia.org/wiki/Google_Chrome "Google Chrome"), [Firefox](https://en.wikipedia.org/wiki/Firefox "Firefox"), [Internet Explorer](https://en.wikipedia.org/wiki/Internet_Explorer "Internet Explorer") 9+, [Safari](https://en.wikipedia.org/wiki/Safari_%28web_browser%29 "Safari (web browser)") 6+ and [Opera](https://en.wikipedia.org/wiki/Opera_%28web_browser%29 "Opera (web browser)") 15+ on desktop browsers, and support for Safari in [iOS](https://en.wikipedia.org/wiki/IOS "IOS") 6+, Chrome and Firefox for [Android](https://en.wikipedia.org/wiki/Android_%28operating_system%29 "Android (operating system)"), [Windows Phone](https://en.wikipedia.org/wiki/Windows_Phone "Windows Phone") 8+, [BlackBerry](https://en.wikipedia.org/wiki/BlackBerry "BlackBerry") 10+ and [Tizen](https://en.wikipedia.org/wiki/Tizen "Tizen").

Additionally, Construct 2 can export to several online marketplaces and platforms, including [Facebook](https://en.wikipedia.org/wiki/Facebook "Facebook"), the [Chrome Web Store](https://en.wikipedia.org/wiki/Chrome_Web_Store "Chrome Web Store"), the Firefox Marketplace, the [Amazon Appstore](https://en.wikipedia.org/wiki/Amazon_Appstore "Amazon Appstore"), Construct Arcade (their own platform to host games made in Construct) and [Kongregate](https://en.wikipedia.org/wiki/Kongregate "Kongregate").[\[14\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-scirra.com-14)[\[15\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-15)

#### Native platforms

Construct has the ability to export to several platforms that provide offline and native application behavior: [Windows](https://en.wikipedia.org/wiki/Microsoft_Windows "Microsoft Windows"), [MacOS](https://en.wikipedia.org/wiki/MacOS "MacOS") and both 32-bit and 64-bit [Linux](https://en.wikipedia.org/wiki/Linux "Linux") are supported by exporting to NW.js. Doing this will allow the user to incorporate several features that HTML5 applications do not normally support, such as file I/O.[\[14\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-scirra.com-14) On October 23, 2012, Scirra announced full support for exporting to [Windows 8](https://en.wikipedia.org/wiki/Windows_8 "Windows 8") [Metro](https://en.wikipedia.org/wiki/Metro_%28design_language%29 "Metro (design language)") applications, including the incorporation of [in-app purchases](https://en.wikipedia.org/wiki/In-app_purchases "In-app purchases"), 'snap' view states, roaming data, sharing, live tiles, touch input and [accelerometer](https://en.wikipedia.org/wiki/Accelerometer "Accelerometer") and [inclinometer](https://en.wikipedia.org/wiki/Inclinometer "Inclinometer") input.[\[16\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-16) Support for exporting to [Windows 10](https://en.wikipedia.org/wiki/Windows_10 "Windows 10") [Universal apps](https://en.wikipedia.org/wiki/Universal_Windows_Platform_apps "Universal Windows Platform apps") was added on August 26, 2015.[\[17\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-17)

Construct handles native mobile support for iOS and Android by using [Cordova](https://en.wikipedia.org/wiki/Apache_Cordova "Apache Cordova").[\[18\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-18)

#### Consoles

On January 20, 2014, Scirra announced that Construct 2 would be receiving support for [Nintendo](https://en.wikipedia.org/wiki/Nintendo "Nintendo")'s [Wii U](https://en.wikipedia.org/wiki/Wii_U "Wii U") system.[\[19\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-19) Later that year, a plug-in was released to make Construct-based games compatible with the [Nintendo Web Framework](https://en.wikipedia.org/wiki/Nintendo_Web_Framework "Nintendo Web Framework").

On April 13, 2016, Scirra announced that Construct 2's [UWP](https://en.wikipedia.org/wiki/Universal_Windows_Platform "Universal Windows Platform") support will allow publishing games to the [Xbox One](https://en.wikipedia.org/wiki/Xbox_One "Xbox One").[\[20\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-20)

### Construct 3

#### HTML5

Construct 3 currently supports web embeds through HTML5, uploading to [Facebook Instant Games](https://en.wikipedia.org/wiki/Social-network_game "Social-network game"), Construct Arcade, as well as being formatted to interactive advertisements.[\[21\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:2-21) It also originally had supported uploading to Kongregate, but it was removed on July 14, 2020, after Kongregate removed submitting new games to the platform.[\[22\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-22)

#### Native platforms & consoles

Construct 3 also supports exporting to Windows, MacOS and Linux through NW.js, Android and iOS through Cordova, and Windows Store through UWP. Construct 3's UWP support also allows exporting to Xbox One, and [Xbox Series X and S](https://en.wikipedia.org/wiki/Xbox_Series_X_and_S "Xbox Series X and S") through [backwards compatibility](https://en.wikipedia.org/wiki/Backwards_compatibility "Backwards compatibility").[\[21\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:2-21)

**Construct Classic** is the first major version of the Construct engine. Unlike its successors, it is a [free and open source](https://en.wikipedia.org/wiki/Free_and_open_source "Free and open source") game engine using DirectX. Originally developed by a group of students,[\[23\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-23) it was first released on October 27, 2007, as version 0.8.[\[24\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-24) The most recent release is r2, released on February 5, 2012.[\[25\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-25)

This version largely defined the software's visual programming language and separately supported [Python](https://en.wikipedia.org/wiki/Python_%28programming_language%29 "Python (programming language)") scripting.[\[26\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-26)

Construct Classic was discontinued on April 20, 2013, to allow the development team to focus more on Construct 2.[\[27\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-27)

**Construct 2** is the second major release of the Construct engine. Major changes include DirectX being replaced with NW.js, allowing projects to be exported to platforms other than Microsoft Windows, including HTML5, Mac OS and Linux. The licensing system also moved from [GPLv2](https://en.wikipedia.org/wiki/GNU_General_Public_License "GNU General Public License") to a proprietary license with a free version available for download.[\[28\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-28)

Construct 2 entered public beta on February 4, 2011,[\[29\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-29)[\[4\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-Create_games_with_Construct_2-4) and was launched on August 22, 2011.[\[30\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-30)

During 2012, Python scripting was retired, citing complications with running Python in browsers and general complexity of maintaining a compatible scripting system.[\[7\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:1-7) A [JavaScript](https://en.wikipedia.org/wiki/JavaScript "JavaScript") SDK for plugins was introduced as a replacement.[\[31\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-31)

On February 20, 2020, Scirra announced plans to discontinue Construct 2, with sales of new licenses retired on July 1, 2020. The software was fully discontinued on July 1, 2021.[\[32\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:3-32)[\[33\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-33)

#### Steam version

On October 18, 2012, Construct 2 was submitted to [Steam Greenlight](https://en.wikipedia.org/wiki/Steam_Greenlight "Steam Greenlight").[\[34\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-34) Construct 2 was in the first batch of software titles to be [greenlit](https://en.wikipedia.org/wiki/Greenlit "Greenlit")[\[35\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-35) on November 30, 2012. On January 26, 2013, Construct 2 was the second software title from Steam Greenlight to be launched on Steam.[\[36\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-36)

On January 17, 2019, it was announced that the Steam version will be delisted from the store on January 31, 2019, due to the phasing out of Construct 2.[\[37\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-37) However, the free version can still be downloaded via unofficial websites or a Steam install link.

### Construct 3

**Construct 3** is the most recent major version of the Construct engine. Announced on January 27, 2015, new features include Mac and Linux support, multi-language support and third-party expansion of the editor with an official plugin SDK for the editor.[\[32\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-:3-32) More details were revealed on February 1, 2017,[\[38\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-38) with a public beta starting on March 28 of the same year.[\[39\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-39) It concluded on December 4, 2017, with the release of the engine. Improvements include an overhauled manual, official tutorials and translations of the IDE.[\[40\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-40)

This version also changed from a pay-once model to a yearly subscription-based model.[\[41\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-41)

On May 23, 2019, JavaScript coding was announced as a separate add-on, but was free for all users who had a paying license before September 2, 2019.[\[42\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-42) The feature was added with r157 on July 5, 2019.[\[43\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-43)

Construct Arcade

**Construct Arcade** (formerly known as Scirra Arcade) is a [game portal](https://en.wikipedia.org/wiki/Digital_distribution_of_video_games "Digital distribution of video games") for projects created in Construct 2 or 3. It was launched on November 23, 2011, along with update r69 of Construct 2.[\[44\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-44) It was later added to Construct 3 on r24.[\[45\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-45)

On August 14, 2019, a new version of the arcade was released, with it being renamed to the Construct Arcade. Changes to the platform includes a new layout, stability improvements, publisher profiles, a way to view analytics of published games on the website and links to other storefronts.[\[46\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-46)

## Construct Animate

**Construct Animate** is an animation tool based on Construct 3 and launched on May 26, 2022, in public beta.[\[47\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-47)

Key differences include absence of game-related features (while maintaining interactivity features) and "faster-than-realtime" video encoding.[\[48\]](https://en.wikipedia.org/wiki/Construct_%28game_engine%29#cite_note-48)
