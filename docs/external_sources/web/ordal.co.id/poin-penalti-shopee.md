## Ketentuan Poin Penalti Shopee

Sebagai informasi, sistem poin penalti Shopee diberikan setiap minggu. Rinciannya sebagai berikut:

### 1. Performa Pesanan

- Tingkat pesanan tidak terselesaikan ≥10% → 1 poin
- ≥10% dan ≥30 pesanan tidak terselesaikan → 2 poin
- ≥60% dan &lt;30 pesanan tidak terselesaikan → 3 poin
- ≥60% dan ≥30 pesanan tidak terselesaikan → 4 poin
- Keterlambatan pengiriman ≥10% → 1 poin
- ≥10% dan ≥50 pesanan terlambat → 2 poin

### 2. Pelanggaran Produk

- Produk terlarang → 1–2 poin + produk dihapus
- Pelanggaran berat (barang palsu, ilegal) → 3–6 poin + pembatasan/blokir
- Produk flora/fauna berbahaya → 1–2 poin + produk dihapus
- Bahasa asing (selain Inggris) → 1 poin + produk dihapus
- Produk imitasi → 1–2 poin + produk dihapus
- Produk palsu/tidak akurat → 1–2 poin + produk dihapus
- Pelanggaran HAKI → 1–2 poin + produk dihapus
- Pelanggaran distribusi merek → 1–2 poin + produk dihapus
- Produk spam atau ubah detail produk lama → 1–6 poin + produk dihapus

### 3. Pengelolaan Produk

- Produk pre-order &gt;20% (jika ≥300 produk) → pembatasan tampilan
- Nama toko melanggar → 2 poin

### 4. Penyalahgunaan

- Subsidi ongkir/voucher → 1 poin
- Kirim paket kosong/salah:

Pertama → 6 poin

Kedua → 9 poin

Ketiga dst. → pembatasan akun

- Alamat retur palsu → 2 poin
- Toko luar negeri tidak resmi → pembatasan/blokir
- Crawling/scraping data → pembatasan akun
- Pesanan/pembeli palsu → 3–9 poin + sanksi tambahan

### 5. Pelayanan Pembeli

- Chat dengan kata kasar/vulgar → 2 poin
- Komentar ulasan tidak pantas atau sebar data pribadi → 2 poin
- Meminta pembatalan lewat chat → 2 poin
- Ajak transaksi di luar Shopee → 2 poin atau pembatasan akun
- Spam atau ancaman via chat → pemblokiran akun

### 6. Konten Shopee Live

- Konten tidak pantas [saat live](https://ordal.co.id/pelanggaran-shopee-live/) (eksplisit, sensitif, dsb) → 3 poin
- Pelanggaran berulang → pembatasan akun

### 7. Transaksi di Luar Shopee

- Cantumkan link, kontak pribadi, media sosial, dll → 2 poin

### 8. Penjualan Hewan

- Gunakan layanan pengiriman tidak sesuai → 1 poin + pembatasan
- Kemasan tidak sesuai standar → 2 poin
- Tidak ada dokumen izin resmi → 2 poin
