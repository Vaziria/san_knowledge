## Done

- **Story design**: [project/bargawa/docs/summaries/story.md](../../../../project/bargawa/docs/summaries/story.md).
  - How the game tells it: one place in seven states, small acts, warm lights that go out, violence off-screen, "he cannot refuse", grief that changes the controls, no score.
  - Seven scenes, one per light state, about 35 minutes: Esuk, Kendi, Dhawuh, Anugrah, Awu, Udan, Sumpah.
  - Each scene has its purpose, what the player does, the symbols, and its lines in Javanese with Indonesian subtitles. Every Javanese line is a draft for the user to check.
- **Model design**: [project/bargawa/docs/summaries/models/](../../../../project/bargawa/docs/summaries/models/index.md).
  - The index holds the character pipeline (MPFB body, game rig, costume by script, bone chains for cloth, face shape keys, GLB) and the budgets.
  - Then one file each: Ramabargawa, Jamadagni, Renuka, the brothers, Citrarata, the props, and the game version of Jatisrana.
  - Soldiers, goats and birds stay off-screen, so they are not modelled for Chapter 1.
- **Design preview**: [project/bargawa/preview/design.html](../../../../project/bargawa/preview/design.html), a local page (no online artifact). It shows the state in the workflow, the game, the colour script, the scenes, a map from `jatisrana.py`, the models, the current Blender stills, the technical plan, the decisions, the open questions, and the steps after acceptance. Checked in headless Edge: light and dark, desktop and 520 px.
- **Checked facts** (my own web searches, no research agents):
  - Godot's latest stable is 4.7.2 (18 Aug 2026; 4.8 is in beta), from the godotengine.org download archive.
  - MPFB 2 needs Blender 4.2 or newer, can add a game-engine rig and Rigify, and MakeHuman's core assets are CC0 ("free to do as you see fit with the asset or derivates").
- **This PC**: an AMD Radeon iGPU with 512 MB, 7.4 GB RAM, 15.9 GB free on D:. The game's budgets are set so that it runs here and on a mid-range phone alike. Godot 4.3 is in Endless Samurai's `tools/`; Blender 5.2 is at `D:\blender\blender.exe`.
