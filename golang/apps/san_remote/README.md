# san_remote

Runs JavaScript in your own browser through the San Remote extension, from a
CLI and from Claude over MCP. Through it, it schedules Threads posts;
uploads, lists, deletes and downloads Vidara videos; and posts to Facebook
(your profile, a Page or a group), schedules, and lists or deletes profile
posts.

- [docs/readme.md](docs/readme.md): install, quickstart, CLI, MCP, Threads,
  Vidara, Facebook, the debug panel, configuration, troubleshooting,
  development.
- [docs/external_repo/san_remote.md](../../../docs/external_repo/san_remote.md)
  in the parent repository: the design and the reasons behind it.
