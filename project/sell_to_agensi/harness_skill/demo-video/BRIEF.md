## Intent

A demo video for the project-brain skill on Agensi.io: a living knowledge graph of a project's markdown, shared by the user and every AI agent session, powered by san_knowledge (Go, embedded graph database goraphdb, MCP server, local graph view on 127.0.0.1:7474). Show the real tool rather than describe it. The user asked for a "demo video", posted to YouTube.

Story: agents forget everything between sessions -> the graph view opening domains into docs into sections -> `explain` answering with a file:line citation -> changed text flagged as outdated -> a finished task linking itself into the graph -> close on the origami crane logo, "project-brain", "on Agensi".
