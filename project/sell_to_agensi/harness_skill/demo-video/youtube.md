# Your AI agent forgot your project again? Meet project-brain

#claudecode #aiagents #knowledgegraph

Every new session, your AI agent starts from zero, so you explain the project again. project-brain turns every markdown file in your project into one living knowledge graph that you and your agents share.

- Answers cite the file and line they came from
- Outdated knowledge is flagged as soon as the text changes
- Finished tasks link themselves into the graph, with what changed and how it was checked
- Runs locally: one Go binary with an embedded graph database, an MCP server for every agent session, and a graph view in your browser. No API key.

Get project-brain on Agensi.io: https://agensi.io

The project shown is a sample (Paperboat, a fictional invoicing app).
