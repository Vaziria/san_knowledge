# Paperboat

Invoicing for freelancers: send an invoice in under a minute, get paid by card or bank transfer, and let Paperboat chase late payments for you.

- Product: [vision](docs/product/vision.md), [pricing](docs/product/pricing.md), [roadmap](docs/product/roadmap.md)
- Specs: [invoice PDF](docs/specs/invoice-pdf.md), [payment reminders](docs/specs/payment-reminders.md), [sign-in](docs/specs/sign-in.md)
- Launch: [launch plan](docs/marketing/launch-plan.md)

## Run it

`make dev` starts the API on port 8080 and the web app on port 3000.
