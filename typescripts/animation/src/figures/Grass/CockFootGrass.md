# CockFootGrass Figure.

Draft written from the code, for the user to correct.

Cock's-foot (Dactylis glomerata): a coarse tussock of broad, folded, blue-green leaves that arch over, and stems topped by seed heads whose lower branches spread like a bird's toes, each ending in a dense cluster of spikelets.

Size: about 0.9 m tall and 0.7 m across by default. Every grass takes its size in meters: `new CockFootGrass({ height, width })`. With only `height`, it keeps its shape; a wider plant grows more leaves and stems, not only longer ones. `seed` grows another plant of the same kind.

No animation behaviour yet: it stands still.
