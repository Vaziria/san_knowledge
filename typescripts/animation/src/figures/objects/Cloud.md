# Cloud Figure.

Draft written from the code, for the user to correct.

A puffy fair-weather cloud (cumulus): a heap of lumpy, rounded clumps on a flat base, rising into a few towers, with smaller billows over its top and sides. It is white (the theme's light colour), shaded greyer toward its flat underside. It is far smaller than a real cloud, so that it fits the scenes. It does not float by itself: the preview lifts it 3 m above the ground.

Size: about 8 m wide, 4 m tall and 5 m deep by default. It takes its size in meters, `new Cloud({ width, height, depth })`, and is built to exactly that size. `seed` builds another cloud of the same kind.

No animation behaviour: it stays still.
