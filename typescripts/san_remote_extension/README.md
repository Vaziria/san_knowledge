# San Remote extension

The browser half of san_remote. It attaches to `san_remote serve` on this
computer and runs the JavaScript and tab commands the server sends, in this
browser's tabs. How to install and use it is in
[golang/apps/san_remote/docs/readme.md](../../golang/apps/san_remote/docs/readme.md).

Manifest V3, Chrome or Edge 135+. Written in TypeScript; the popup and the
debug side panel use React and Chakra UI. Vite builds it into `dist/`.

```powershell
npm install
npm run build      # typecheck + build into dist/
npm run dev        # rebuild on change; then reload the extension
npm run gen        # regenerate src/gen from the proto (runs buf in golang/apps/san_remote)
```

To install, open `chrome://extensions`, turn on Developer mode, use **Load
unpacked** on `dist/`, then turn on **Allow User Scripts** in the
extension's Details. The `key` in `public/manifest.json` fixes the
extension id to `kmlmiiljeiakjbilabmpdiegmoagkmkg`, which the server checks.

## Files

- `src/background/`: the service worker, plain TypeScript.
  - `index.ts` attaches to the server, keeps the worker alive, reattaches,
    and logs each command.
  - `commands.ts` runs the commands: tabs through `chrome.tabs`, code
    through `chrome.userScripts.execute`.
- `src/popup/`: the popup. It shows the connection status, warns when Allow
  User Scripts is off, opens the debug panel, and has the server URL and
  browser name settings.
- `src/sidepanel/`: the debug panel. It shows every command the server
  sent, with its reply, live.
- `src/log.ts`: the command log behind the panel, in
  `chrome.storage.session`. Only the worker writes it; the panel asks the
  worker to clear it.
- `src/settings.ts`: settings in `chrome.storage.local`, and the status the
  worker writes to `chrome.storage.session`.
- `src/ui.tsx`: mounting a page in Chakra, and the status badge.
- `src/gen/`: generated by `protoc-gen-es`. Don't edit it.
- `public/icons/`: the icon, a browser window with a `>_` prompt in dark grey
  (`#3c4043`). `icon.svg` is the source. The PNGs (16, 32, 48, 128) were
  drawn from it on a canvas in headless Chrome, so redraw them when the SVG
  changes.
