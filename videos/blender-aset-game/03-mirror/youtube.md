# Satu Tiang Jadi Dua: Cara Pakai Mirror Modifier di Blender

#blender #tutorialblender #belajarblender

Mirror modifier mencerminkan bentuk terhadap origin objeknya:
- Klik tiang, tab Modifier, Add Modifier, Generate, Mirror
- Belum terlihat, karena cerminnya ada di origin, tepat di tengah tiang
- Tab, A, lalu G, X, 1.5: geser bentuknya, origin tetap di tengah
Jarak antar tiang = dua kali jarak bentuk ke origin.

Bagian 3 dari seri Blender untuk Aset Game. Blender 5.2, pengaturan bawaan.
